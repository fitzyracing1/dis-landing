# DIS landing page

The static landing page for [DIS](https://github.com/fitzyracing1/DIS), a self-hostable lit/dark status bot.

Live: https://fitzyracing1.github.io/dis-landing/

Plain HTML and CSS (`index.html`, `style.css`), served by GitHub Pages from `main`. No build step, no scripts, no tracking, no external fonts.
